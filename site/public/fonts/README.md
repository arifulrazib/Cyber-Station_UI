# Fonts

All UI in this repo uses **Gilroy** (commercial font, not included because of its licence).

Add your licensed web font files to `site/public/fonts/` with these exact names:

| Weight | File |
|---|---|
| 400 | `Gilroy-Regular.woff2` |
| 500 | `Gilroy-Medium.woff2` |
| 600 | `Gilroy-SemiBold.woff2` |
| 700 | `Gilroy-Bold.woff2` |
| 800 | `Gilroy-ExtraBold.woff2` |

`.woff` files with the same names also work. If Gilroy is installed on your computer, the
mockups use it even without these files. Otherwise the browser's system font is used.
